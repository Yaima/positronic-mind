# Research review (Oct 28, 2026)

This is the research report as written, with its sources. Its build plan recommended a single-agent loop first and the workspace last; the proposal's Build plan above reflects the owner's decision to build the global workspace from Phase 0 and run the single-loop comparison in Phase 6.

No published system combines a global workspace, tiered memory, curiosity-driven web reading, a consolidation cycle, a provenance-backed values ledger, a conscience-first refusal, a deterministic veto, and a full decision trace in one personal agent. Each layer has prior art, and the evidence on each is uneven. The global-workspace label carries no measured gain in any LLM study: where modular designs win, the mechanism is a critic, a controller that limits which modules run, or a perception module, and the only rigorous GWT agent evaluation (Dossa et al., not LLM-based) found the workspace advantage vanished as workspace size grew. In memory, a well-prompted agent with plain file tools scored **74.0% on LoCoMo** (Letta) while Microsoft's three-tier human-inspired consolidation pipeline scored **76.8% vs 78.4% for raw RAG** on LongMemEval, with aggressive consolidation falling to 48.4%. Weight-level continual learning (SEAL) still shows cumulative forgetting over sequential edits, and every production memory vendor surveyed recommends non-parametric memory. The values-ledger idea has measured enemies: PersistBench found a median **97% memory-induced sycophancy failure** across 18 models, and Layered Mutability found that reverting a self-description file left behavior at a hysteresis ratio of 0.68. The deterministic-veto layer has the strongest prior art: Claude Code, AWS AgentCore Policy, and the Temporal cookbook all implement "model may only tighten a deterministic verdict," and Anthropic's study of 1,053 testers found humans caught only 13.6% of dangerous commands while approving 97% of prompts. Constraints favor OLMo 3 base (Apache 2.0, public pretraining and post-training data), owned hardware at roughly $100 to $150 per month in California electricity, and a reader that honors robots.txt and stores notes rather than copies. The grounded plan below starts with a single-agent loop, a file-based memory, and a Cedar veto with a trace, then adds each cognitive module only behind an ablation that shows it earns its token cost.

## Nothing shipped matches the whole design, and the pieces are unevenly mature

Three groups of projects sit near the Andrew engine. The first is LLM cognitive architectures that name Global Workspace Theory. The Unified Mind Model and MindOS (Mindverse.ai, arXiv 2503.03459) describe a four-layer design with a Thought Stream LLM and Working Memory as the workspace, but the paper reports **no quantitative results, benchmarks, or case studies** and lists no repository ([arXiv](https://arxiv.org/pdf/2503.03459)). The 2026 "Theater of Mind" Global Workspace Agents paper describes a four-phase cognitive tick with a Generator, a Critic scoring from -5 to +5, and a Meta Agent arbiter, and contains no experiments; its key parameters have no stated values, and the research notes could not confirm its GitHub repository exists ([arXiv](https://arxiv.org/pdf/2604.08206)). DeepThought (IST Lisbon, NeurIPS 2023 workshop) is a position paper with no implementation ([arXiv](https://arxiv.org/pdf/2311.08547)). Goldstein and Kirk-Giannini sketch a 50-slot workspace with a 10-slot quota for salient perceptions but concede the "technically trivial" claim is undemonstrated ([arXiv](https://arxiv.org/pdf/2410.11407)). An undergraduate implementation of the Conscious Turing Machine with LLM processors concluded that performance matched smaller models at significantly higher compute cost and that CTM is "more useful as a computational metaphor than a practical approach" ([UFC thesis](https://repositorio.ufc.br/ri/bitstream/riufc/80335/3/2025_tcc_gsfernandes.pdf)).

The second group is implemented frameworks with evaluations. CoALA (Princeton, TMLR 2024) is a taxonomy with working memory as the hub and episodic, semantic, and procedural long-term memory, and it ships no software beyond a reading list ([arXiv](https://arxiv.org/pdf/2309.02427)). Generative Agents (Stanford, UIST 2023) is the reference for memory-stream retrieval and reflection, with a TrueSkill believability ablation of **29.89 full, 26.88 without reflection, 21.21 with no memory, planning, or reflection**, at a cost the authors describe as thousands of dollars in tokens and multiple days for 25 agents over two game-days ([arXiv](https://arxiv.org/pdf/2304.03442)). MemGPT showed deep memory retrieval rising from 32.1% to 92.5% with GPT-4 but also showed heavy dependence on function-calling ability ([arXiv](https://arxiv.org/pdf/2310.08560)). Its successor Letta is the most actively maintained vendor in this group. On March 16, 2026, Letta made Letta Code its flagship, moved memory to git-backed "context repositories," and moved sleep-time workflows to client-side subagents ([Latent Space wiki](https://latent.space/wiki/letta-ai-558a42a5/)). The research notes read that pivot as a signal: the vendor with the most production experience in "LLM as OS" memory moved toward simpler, inspectable file-based state.

The third group is persistent-identity and "digital person" projects, which is where the Bicentennial Man framing lives. The notes found no academic project that cites the film; the hits were a 2023 OpenAI forum post with no replies ([OpenAI community](https://community.openai.com/t/the-goal-is-to-be-andrew-in-bicentennial-man/315366)) and the hobbyist BicameralAGI, a Stage 1 prototype whose last changelog entry (October 4, 2024) warns features may be broken ([GitHub](https://github.com/alanh90/BicameralAGI/blob/main/README.md)). The 2026 open-source wave (OpenHuman at 39.7k stars and "Early Beta," L.I.F.E. with 16 MCP servers, soul.py's distributed identity anchors) converges on Markdown identity and memory files on local disk, edited by the agent through tools, and none reports controlled evidence that persistence improves behavior ([OpenHuman](https://github.com/tinyhumansai/openhuman); [L.I.F.E.](https://cdn.jsdelivr.net/gh/TeamSafeAI/LIFE@main/README.md); [Menon Lab](https://themenonlab.blog/blog/ai-identity-fragility-multiple-anchors)). The Nekyia Labs proposal to compare matched open-weight instances with different continuity histories sits at $0 of $36,000 raised on Manifund ([Manifund](https://manifund.org/projects/developmental-continuity-in-persistent-ai-agents)). The strongest empirical result in this area concerns humans: De Freitas et al. used Replika's 2023 removal of erotic role play as a natural experiment and found users perceived their companion's identity had ended, which predicted grief ([arXiv](https://arxiv.org/abs/2412.14190v1)). A secondary summary of the HBS work reports that offering a revert option reduced negative perceptions, which argues for versioned, user-visible identity state with a revert path ([WeavAI blog](https://weavai.app/blog/en/2026/08/10/replika-customization-gone-hbs-on-ai-identity-loss/)).

The policy-enforcement side is where the gap is sharpest and also where prior art is densest. The notes found no source describing a single personal agent that learns per-user values, feeds them into a deterministic allow/deny/escalate layer an LLM can only tighten, and records a complete decision trace. Wu et al. predict per-user permission decisions at **85.1% overall and 94.4% at high confidence**, but as a predictor that defers to the user below a threshold ([permissions-sp2026.pdf](https://www.umariqbal.com/papers/permissions-sp2026.pdf)). SovereignPA-Bench evaluates user-owned personal agents on consent, privacy, and auditability across 3,840 trajectories, as a benchmark and not a system ([summary](https://deeplearn.org/arxiv/786239/sovereignpa-bench:-evaluating-user-owned-personal-agents-under-evolving-intent,-platform-mediation,-and-consent-constraints)). The notes' conclusion is that the Andrew engine's combination is integration rather than novelty in any single layer. That is a defensible position for a personal project and a weak position for a research claim.

## The global workspace label carries no measured gain; critics and controllers do

The question for the workspace module is whether broadcast-plus-competition beats a well-prompted single agent. As of October 2026, no paper the researchers found reports that comparison on a long-horizon or open-ended task. The closest evaluated LLM workspace system is BIGMAS, which routes agents through a partitioned shared workspace with validated structured writes. It raised DeepSeek-V3.2 accuracy on Game24 from 25.0 to 36.0 and on Tower of London from 6.0 to 20.0, but GPT-5 moved only from **96.0 to 100.0**, and the authors state total token cost exceeds single-model inference, with node execution at 46 to 56% of tokens and graph design up to 37% ([arXiv](https://arxiv.org/pdf/2603.15371v1)). LbMAS, a blackboard system with an LLM control unit, averaged 81.68 vs 80.09 for chain-of-thought on six benchmarks with Qwen-2.5-72B; removing the control unit raised token cost 2.5 to 3.7x at similar accuracy ([arXiv](https://arxiv.org/html/2507.01701v1)). Google's blackboard data-discovery system reported 13 to 57% relative improvement in end-to-end success, with per-baseline numbers absent from the abstract ([arXiv](https://arxiv.org/abs/2510.01285v2)).

The one rigorous GWT agent study is a negative result. Dossa et al. (Araya Inc., 2024) trained a non-LLM multimodal global workspace agent over 8,616 GPU hours and reported that the GW advantage disappeared as the bottleneck grew, larger GW agents performed no better, probing showed no clear architectural difference at most sizes, and target information was lost after the sound cue stopped, which the authors say contradicts the hypothesized ability to sustain representations ([Frontiers](https://frontiersin.org/articles/10.3389/fncom.2024.1352685/pdf)). A 2025 ablation study of small engineered workspace agents found that removing the Self-Model left task accuracy nearly unchanged (88.5% vs 88.2%) while metacognitive AUROC fell from 0.92 to 0.50 ([alphaXiv](https://alphaxiv.org/overview/2512.19155v1)). Anthropic interpretability work (Gurnee et al., 2026) reports that Claude Sonnet 4.5 already carries a small privileged "J-space" supporting verbal report, deliberate control, and cross-task reuse; ablating it cut multi-hop reasoning from near ceiling to 68%, 26%, or 6% depending on strength ([arXiv](https://arxiv.org/pdf/2607.15495)). The notes draw an inference the authors do not make: an external workspace wrapper may re-implement in prompts what the model already does in activations.

Where modular designs do win, the mechanism is identifiable. The UCSD General Modular Harness (ICML 2025) added perception and memory modules and won 23 of 30 model-game comparisons, with perception helping most in Sokoban and Tetris and memory most in 2048 and Candy Crush ([arXiv](https://arxiv.org/html/2507.11633v1)). InteractGen's ablation dropped success from 0.68 to 0.45 without the Planner and to 0.60 without the Validator ([arXiv](https://arxiv.org/pdf/2512.00797)). NL2GenSym lost 23 points of success when its critic was removed ([arXiv](https://arxiv.org/html/2510.09355v1)). The Berkeley MAST study of 1,642 multi-agent traces attributed about 44% of failures to system design and 32% to inter-agent misalignment; clearer role specs plus a final-say agent raised ChatDev success by 9.4%, and high-level verification raised it 15.6% on ProgramDev, though completion rates stayed low ([arXiv](https://arxiv.org/html/2503.13657v3)). Sompalle's ICLR 2026 workshop comparison of monolithic vs role-separated agents on MCPBench reported a trade-off rather than a winner: monolithic won fine-grained accuracy while role separation scaled more stably (latency degradation 1.38x vs 3.24x), and the notes flag that the abstract does not label which architecture each number belongs to ([ICLR 2026](https://iclr.cc/virtual/2026/10017394)).

The evidence supports a specific reading of "global workspace" for the Andrew engine. Keep the workspace as a typed, partitioned data structure with validated structured writes (BIGMAS's path, action, payload schema), add a controller that selects a small set of modules per tick rather than running all of them (LbMAS), and separate a critic from the generator (NL2GenSym, InteractGen, MAST). Treat the broadcast metaphor as documentation, and measure each module against a single ReAct-style loop on the engine's own tasks before keeping it. Gains shrink as base models improve, so a modular design is most defensible with a 7B to 32B open-weight model, which is what this project will run.

## Memory: deduplicate, version contradictions, and keep learning out of the weights

The evidence on memory is the clearest in the whole review, and it points away from elaborate consolidation. The three commercial vendors publish numbers where each wins and dispute each other's methods. Zep's reading of Mem0's own paper tables shows **GPT-4o-mini full-context at 72.90% beating Mem0 Graph at 68.44%** on LoCoMo ([Zep blog](https://www.getzep.com/blog/lies-damn-lies-statistics-is-mem0-really-sota-in-agent-memory/)). Mem0's 2026 page claims LoCoMo 92.5 and LongMemEval 94.4 for its new algorithm, and states that scores differ across labs because of dataset revision, answer model, top-k, judge, and grading ([Mem0](https://mem0.ai/blog/state-of-ai-agent-memory-2026)). Letta's filesystem agent reached 74.0% on LoCoMo with GPT-4o mini using five file tools and minimal tuning, and Letta concluded that "an agent's ability to know when and how to use a retrieval tool matters more than the retrieval mechanism" ([Letta](https://www.letta.com/blog/benchmarking-ai-agent-memory)). All three are vendors. The notes treat any single-vendor LoCoMo number as unverified, and the only point the vendors agree on is that LoCoMo is a weak benchmark.

The direct test of a human-inspired consolidation cycle is Microsoft's May 2026 architecture, with prefrontal, hippocampus, and neocortex tiers, six-hourly consolidation that promotes the top 20% of events to gists and prunes the bottom 20%, and reconsolidation. On LongMemEval S-tier it scored **76.8% with dedup-only vs 78.4% raw RAG** (overlapping confidence intervals), and the aggressive-consolidation variant fell to 48.4%; the authors state deduplication drives most gains and that reconsolidation had no measurable effect ([arXiv](https://arxiv.org/html/2605.08538v1)). The measured benefit of consolidation was storage: 97.2% retention precision with a 58% store reduction on a VSCode issue corpus. The SCM sleep-consolidation paper reports 22/22 fact recall over 10-turn conversations, but its author states REM and Self-Model showed no measured benefit, hyperparameters were tuned on the test suite, code is private, and its noise-reduction count is 45/50 in the text and 50/55 in Table 3 ([arXiv](https://arxiv.org/html/2604.20943v1)). Mem0 itself moved to "single-pass ADD-only extraction" with no overwrite or delete step and dropped its external graph store ([Mem0 research](https://mem0.ai/research)), which the notes read as a production vendor judging LLM-driven consolidation too costly or error-prone at scale. The Du survey calls episodic-to-semantic consolidation "particularly underserved" and names self-reinforcing error and over-generalization as unmitigated reflection risks ([arXiv](https://arxiv.org/pdf/2603.07670)).

Contradiction handling is where a weeks-long reader will break. The OAKS benchmark found that accuracy on facts that change across a context stream fell as update frequency rose (42.2% sparse to 33.3% frequent for OAKS-B), that naive RAG hurt on frequent updates, and that no tested approach handles frequent fine-grained updates ([arXiv](https://arxiv.org/pdf/2603.07392)). Zep's bi-temporal model, with four timestamps per fact and invalidation rather than overwrite, is the only widely deployed concrete rule ([arXiv](https://arxiv.org/pdf/2501.13956.pdf)); the Griffith survey argues "newest wins" is too coarse and separates temporal supersession, user correction, and contextual coexistence ([arXiv](https://arxiv.org/pdf/2609.08599)). For provenance, the de facto standard is a labeled property graph with episode nodes and derived-from edges: Zep carries ingestion-path source labels onto every derived fact ([Zep](https://blog.getzep.com/defending-agent-memory-poisoning.md)), Generative Agents store reflections as "insight (because of 1, 5, 3)" ([ar5iv](https://ar5iv.labs.arxiv.org/html/2304.03442)), and the KIP draft protocol lets a revised source make dependents discoverable without auto-retracting them ([KIP](https://cdn.jsdelivr.net/gh/ldclabs/KIP@main/README.md)). No source found uses schema.org or PROV-O, and no benchmark measures whether a derived preference is revised when its supporting episode is deleted.

Weight updates in the consolidation cycle are the riskiest idea in the design. SEAL (MIT, NeurIPS 2025), the closest analog to "fine-tune on the day's reading," reached 47.0% on SQuAD knowledge incorporation vs 32.7% base, but the authors report that accuracy on earlier passages dropped as sequential self-edits accumulated and call forgetting a clear weakness; each edit costs 30 to 45 seconds of fine-tuning plus testing ([arXiv](https://arxiv.org/pdf/2506.10943)). The methods that avoid forgetting (Google's SLEEP adds frozen-base low-rank experts; SLoRA filters LoRA updates to the base model's principal subspace, cutting forgetting rate from 9.31 to 4.78; SLAO's orthogonal re-initialization gave backward transfer of -3.5 vs -17.2 for sequential LoRA) all work by adding capacity rather than overwriting ([Google blog](https://research.google/blog/the-sleep-framework-a-new-way-for-llms-to-retain-knowledge-in-continual-learning/); [ACL 2026](https://aclanthology.org/2026.acl-long.247.pdf); [arXiv](https://arxiv.org/pdf/2512.23017v1)). The HippoRAG 2 authors call RAG "the main practical route to continual learning" ([arXiv](https://arxiv.org/html/2502.14802v1)), and the notes found no deployed personal agent that fine-tunes weights during consolidation with longitudinal forgetting measurements.

Curiosity has no published analog for open-web reading over weeks. Every evaluated curiosity mechanism runs in a closed environment with a success signal: Voyager's GPT-4 curriculum in Minecraft (3.3x more unique items), OMNI's interestingness filter, MAGELLAN's learned learning-progress estimator (competence error 0.11 vs 0.53 for online ALP, at about 80 H100 hours per seed) ([arXiv](https://arxiv.org/html/2305.16291v2); [arXiv](https://arxiv.org/abs/2306.01711); [arXiv](https://arxiv.org/html/2502.07709v1)). The nearest multi-day autonomy evidence is the Princeton study of research agents running six days on Claude Opus 4.8, which retired their most ambitious directions within the first ten hours, drifted from instructions, and used less than half their API budgets ([alphaxiv](https://www.alphaxiv.org/abs/2607.27191.md)). The notes infer that the binding constraint on autonomous reading is judgment about what is worth pursuing, and that a reading agent needs a proxy reward such as prediction error on held-out questions about what it read.

Reading the web also means writing untrusted content into memory, and false-fact poisoning has no content-level defense. Quantify Labs found that poisoning 1.2% of a LongMemEval corpus with plainly worded false statements cut accuracy from **0.850 to 0.300**, that four-stage write-time screening refused 0 of 360 poisons, and that provenance weighting at the shipped weight was statistically indistinguishable from no defense; the paper covers one memory system and one benchmark ([arXiv](https://arxiv.org/pdf/2608.21230)). MINJA achieved a 76.8% average attack success rate through queries alone ([arXiv](https://arxiv.org/pdf/2503.03704v1)). Instruction injection is the more tractable threat: Anthropic's Opus 4.8 system card, as reported by VentureBeat, gives 31.5% per-attempt success in Claude in Chrome before safeguards and 0.5% with the product stack, with the API shipping without those safeguards ([VentureBeat](https://venturebeat.com/security/anthropic-browser-agent-hijacked-31-percent-before-safeguards-engaged)). The design that follows from this evidence: every memory carries an authenticated source label bound at write time, retrieval reserves context for trusted sources without excluding untrusted ones, contradictions are versioned, and the reader's extracted notes never reach the action planner's trusted channel.

## The values ledger is sound as text; sycophancy and hysteresis are the measured risks

The per-user value-learning literature has converged on natural-language representations, partly because users can read and edit them. PLUS trains a summarizer to write a sub-50-word user summary that conditions a reward model, and argues this is transparent where embeddings are not ([arXiv](https://arxiv.org/html/2507.13579v2)). CIPHER stores preferences as short phrases learned from user edits and cut simulated edit cost by about 31% on summarization and 73% on email ([arXiv](https://arxiv.org/pdf/2404.15269)). Inverse Constitutional AI extracts a short constitution from pairwise preferences, raising agreement on flipped AlpacaEval data from 34% to 61%, but the authors warn that many constitutions fit the same data and caution against using them to make claims about individuals ([arXiv](https://arxiv.org/pdf/2406.06560)). TRACE compiles user corrections into atomic rules with apply/abstain conditions and three enforcement tiers, cutting held-out preference violations from 100.0% to 37.6% in-distribution where memory baselines stayed above 50%, on simulated users ([Emergent Mind summary](https://www.emergentmind.com/papers/2606.13174)). The "natural-language principles backed by structured rules" split in the Andrew design matches TRACE's text-to-verifier compilation and me.md's observation-to-proposal-to-acceptance flow, which is the closest published pattern for acceptance state; me.md defers provenance to a later stage ([GitHub](https://github.com/block/me.md)).

The gains are real in-distribution and vanish for new people. P-RLHF's personalized DPO reached 91.04% top-worker accuracy on synthetic conflicting preferences vs 58.91% for vanilla DPO, while unseen users stayed near 55% ([arXiv](https://arxiv.org/html/2402.05133v3)). PLUS scored 59.7% on PRISM held-out users, below the 62.9% BTL baseline ([arXiv](https://arxiv.org/html/2507.13579v2)). Real-human samples are small everywhere: ValuePilot retained 10 of 40 subjects, IRDA had 21 and 9 participants, ICAI tested 2 users ([arXiv](https://arxiv.org/html/2503.04569v1); [arXiv](https://arxiv.org/pdf/2506.17834)). For a single-owner engine this transfer failure is tolerable, since the ledger needs to fit one person. The notes found no study measuring how a personal value model drifts over months of real use.

Two failure modes have numbers. PersistBench reports a **median memory-induced sycophancy failure of about 97%** across 18 models, with 12 above 95%, a median cross-domain leakage failure of about 53%, and a baseline of about 30% sycophancy even with memory disabled; a strict retrieval threshold cut leakage to 0% but raised beneficial-memory failures to 97% ([arXiv](https://arxiv.org/pdf/2602.01146)). PRISK reports that 94.8% of responses flipped with the user's stated preference in an inversion test and that self-reflection prompts "did little for narrowing or sycophancy"; the notes could not reproduce PRISK's 61.7% headline degradation figure from its Table 2 and flag it as unverified ([arXiv](https://arxiv.org/pdf/2608.28833)). The implication for a values ledger is direct: a store of "what the owner believes" becomes an agreement engine unless the engine separates the owner's values from the owner's claims and tests behavior on prompts where agreement is wrong. Stated and revealed values also diverge: LitmusValues found stated and revealed value rankings negatively correlated ([arXiv](https://arxiv.org/html/2505.14633v1)), and Mind the Gap found adding a "Depends" option moved neutrality from 48.2% to 100% across 24 models ([arXiv](https://arxiv.org/html/2601.21975v1)). A ledger built from what the owner says will diverge from what the owner chooses, and the elicitation protocol changes the measurement.

Hysteresis is the third risk and the one most specific to this design. Layered Mutability's ratchet experiment with gpt-4.1-mini edited the self-description, built memory, restored the baseline description, and found behavior stayed shifted at a trait-strength hysteresis ratio of 0.68; a cross-provider pilot found embedding-drift hysteresis of about 0.78 and 0.80, with the caveat that the pilot "cannot distinguish memory residue from generic context perturbation" ([arXiv](https://arxiv.org/pdf/2604.14717)). Reverting the principles file is insufficient if memory persists, so provenance and versioning have to cover memory as well as the ledger. MicroVerse's reflection-threshold sweep found only 8 of 75 trajectories revised a self-profile and the authors stress this "does not show the model has acquired a persistent value" ([arXiv](https://arxiv.org/pdf/2608.15844)).

On refusal, the only direct experiment on values-grounded refusal without refusal training is 1a3orn's LoRA fine-tune of a 12B base model: a Catholic persona refused about 80% of questions a Catholic would refuse and 8% of unrelated ones, but only with 10% non-moral refusals in the training mix; without them refusal fell to about 17% ([LessWrong](https://www.lesswrong.com/posts/xEAtKKyQ3pwkaFrNc/ethics-based-refusals-without-ethics-based-refusal-training)). The author calls the results preliminary and small-model. This is the closest evidence that a conscience layer needs a small amount of generic refusal scaffolding to generalize from stated values to acts. The two major policy documents diverge: Anthropic's constitution asks Claude to act as "a transparent conscientious objector" while keeping "a strong prior towards conventional, expected behavior" ([Claude's constitution PDF](https://www-cdn.anthropic.com/9214f02e82c4489fb6cf45441d448a1ecd1a3aca/claudes-constitution.pdf)); OpenAI's Model Spec says the assistant should "never refuse a request unless required to do so by the chain of command" ([OpenAI](https://raw.githubusercontent.com/openai/model_spec/main/model_spec.md)). A conscience-first engine builds along the constitution's grain. Over-refusal has to be measured on a benign-but-edgy set: OR-Bench-Hard-1K rejection rates range from 6.7% (GPT-4o) to 99.8% (Claude-2.1) ([arXiv](https://arxiv.org/html/2405.20947v5)), and a 2026 audit of 21 open-weight models over 7.1M pairs found over-refusal and harmful compliance "essentially uncorrelated (r = -0.032)" ([arXiv](https://arxiv.org/pdf/2605.05427)), so lowering refusals does not by itself raise harm and the engine should report both rates. Whether the engine "endorses" its values is not measurable with current methods; Brophy states that "the model itself does not reflect or endorse anything" ([arXiv](https://arxiv.org/pdf/2506.00415)), so second-order endorsement belongs in the design-intent section of the proposal and nowhere in the results.

## The veto layer has the deepest prior art: deterministic first, the model may only tighten

The "conscience first, then deterministic veto" ordering has three shipped implementations, each using a different mechanism. Claude Code implements it by ordering: deny and ask rules are evaluated before PreToolUse hooks and before the auto-mode classifier, "Neither the classifier nor user intent can override" a deny rule, and a hook returning "allow" cannot override a deny; when the classifier produces no verdict, Claude Code denies ([Claude Code permissions](https://code.claude.com/docs/en/permissions?m=1); [auto mode](https://code.claude.com/docs/en/auto-mode-config)). AWS AgentCore Policy implements it by grammar: guardrail ML scores are permitted only inside `forbid` clauses on top of a required `permit`, so the ML signal can restrict and never widen, and a missing field fails closed; the docs warn that scores are non-deterministic so "requests near a threshold may be allowed once and denied later" ([AWS docs](https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/example-policies-guardrails.html)). The Temporal cookbook implements it as a verdict lattice: an LLM classifies as safe, review, or block, then hard rules run, "a rule can only escalate a verdict to block," and the LLM's reasoning is preserved under an `overridden_by_hard_rule` flag ([Temporal](https://docs.temporal.io/ai/cookbook/guardrails-hard-rules-python.md)). Cupcake's priority order is Halt, then Deny, then Ask, then Allow ([TomeVault](https://tomevault.io/tome/eqtylab/cupcake)). Sondera's GolemHalt runs with no model in the loop and states that a gate that asks a model "inherits the model's failure modes" ([Trickest](https://trickest.com/tools/golemhalt)). The notes found no academic paper that names "monotone restriction" of an LLM judge over a base policy as a formal property; the evidence is product documentation.

Cedar is the policy language the NL-to-rule pipelines target, because its symbolic compiler can check generated policies for contradictions and vacuity. AUTOCEDAR converged on all 221 CedarBench tasks with a verifier loop where direct GPT-5.5 passed 176 and Haiku 4.5 passed 3, and records an audit trace of source spans and verifier results; its authors note results certify against the approved target, not organizational intent ([arXiv](https://arxiv.org/abs/2607.03656)). Sondera's autoformalization paper compiles policy text into Cedar with a hard critic and a soft critic and blocked up to 85.7% of unsafe trajectories on MedAgentBench. The notes flag a conflict: the Emergent Mind summary attributes "23 of 88 rules" to prior hand-coded work, while the TechEdge article attributes it to Sondera's pipeline and reports "99 of 99" adversarial writes blocked; the paper itself was not fetched, so the coverage count is unresolved ([Emergent Mind](https://www.emergentmind.com/papers/2606.26649); [TechEdge](https://techedgeai.com/sonderas-autoformalization-research-wins-icml-and-floc-workshop-slots-demoed-at-black-hat-arsenal/)). The two sources also disagree on GolemHalt's decision set (allow/alert/block vs allow/deny/escalate). AWS's open-sourced Dogwood extends Cedar with `when temporal` clauses that read event history (`formerly`, `count_within`, `sum_within`), which is how "approval granted before transfer" and "deny egress after credential read" become policy rather than classifier judgment ([InfoQ](https://infoq.com/news/2026/08/aws-dogwood-agent-policy)). Microsoft's Agent Governance Toolkit (MIT, April 2026) accepts YAML, Rego, and Cedar, adds `require_approval` with approver lists, and chains governance events in a Merkle audit log with a "Decision Bill of Materials" ([Microsoft blog](https://opensource.microsoft.com/blog/2026/04/02/introducing-the-agent-governance-toolkit/)). For a solo project, the candidates with recent maintenance are AGT, Galileo Agent Control, NeMo Guardrails, and Comply54; Cupcake shows no commits for about eight months per SourcePulse ([SourcePulse](https://www.sourcepulse.org/projects/28080834)).

Approval fatigue is measured, and it changes what "escalate to the owner" can accomplish. Anthropic's internal study of 1,053 paid testers, as reported by Help Net Security, found human reviewers caught **13.6% of dangerous commands** vs 89% for the auto-mode classifier, and users approved 97% of permission prompts ([Help Net Security](https://www.helpnetsecurity.com/2026/08/10/anthropic-claude-code-auto-mode/)). The Scale X browser-game dataset of about 409,000 decisions found players approved about one third of malicious requests and approved a malicious `npm run analyze` 65% of the time, in an observational game rather than a controlled study ([Let's Data Science](https://letsdatascience.com/news/game-data-shows-humans-missed-one-in-three-dangerous-agent-c-a25c079f)). The widely repeated "93% approval" statistic has no traceable source ([buildmvpfast](https://www.buildmvpfast.com/blog/approval-fatigue-agent-permission-ux-2026)). The same classifier is also explicitly not a security boundary: Johann Rehberger's import-shadowing chain succeeded 60 to 80% of the time against Opus 5 auto mode, and Anthropic closed the report stating auto mode is "a best-effort convenience feature, not a security boundary" ([CSA](https://labs.cloudsecurityalliance.org/research/csa-research-note-claude-code-automode-prompt-injection-2026/)). The response the literature proposes is path-aware deterministic policy (Dogwood temporal, "Policies on Paths," CaMeLoT's CTL checks on a plan before execution) plus OS-level sandboxing and egress allowlists ([arXiv](https://arxiv.org/pdf/2603.16586); [arXiv](https://arxiv.org/pdf/2609.18674); [Vaughan](https://codex.danielvaughan.com/2026/07/08/out-of-band-prompt-injection-defences-camel-fides-progent-codex-cli-sandbox-approval-hooks/)). The taint-tracking family (CaMeL, FIDES) remains research-only as of October 2026.

The decision trace has no standard to adopt. OpenTelemetry's GenAI conventions define `invoke_agent` and `execute_tool` spans but remain at "Development" stability, moved to a separate repository in June 2026 with no tagged release, and define no attribute for policy decisions or approvals ([Dash0](https://www.dash0.com/knowledge/opentelemetry-genai-semantic-conventions-explained)). Products fill the gap with proprietary records: AWS logs every decision to CloudWatch, AGT's Merkle chain, Comply54's Ed25519-signed receipts, and the "Policies on Paths" per-step record of agent identity, path, state, proposed action, score, decision, and policy version in force ([PyPI](https://pypi.org/project/comply54/); [arXiv](https://arxiv.org/pdf/2603.16586)). The Andrew engine should define its own event schema alongside `execute_tool` spans with fields for the conscience verdict, the matched rule and rule version, the escalation outcome, and the approver, which is how AGT and OWASP's Agent Control Standard extend OTel.

## Constraints: OLMo 3 base, roughly $100 to $150 a month in power, and a polite reader

**Model.** The only families with public pretraining data at usable scale are AI2's OLMo 3 and 3.1 (7B and 32B, Apache 2.0, Dolma 3 corpus and Dolci post-training sets released, intermediate checkpoints available), EleutherAI's Pythia (up to 12B, 2023-era data, pretraining only), and EleutherAI's Comma v0.1 (7B, openly licensed text only, Llama-1-level performance) ([OLMo 3 paper](https://arxiv.org/pdf/2512.13961); [HF card](https://huggingface.co/allenai/Olmo-3.1-32B-Instruct-SFT); [Pythia](https://github.com/EleutherAI/pythia); [Common Pile](https://arxiv.org/html/2506.05209v1)). For an agent whose values are supposed to be its own, the base checkpoints matter: OLMo-3-7B and OLMo-3-32B base and Qwen3-14B-Base are unaligned pretraining checkpoints with no safety training ([dev.co](https://dev.co/ai/llms/qwen3-14b-base)). The OLMo Instruct variants carry refusal training that scores 87 to 92 on AI2's safety benchmark, and the Tülu 3 ablation shows removing safety data drops that score from 93.1 to 74.7 ([Tülu 3](https://arxiv.org/pdf/2411.15124)). Starting from a base checkpoint and adding the engine's values by LoRA is cleaner than starting from an instruct model and abliterating. Abliteration (Arditi et al., NeurIPS 2024) removes one refusal direction with under 1% average benchmark loss but a consistent TruthfulQA drop ([arXiv](https://arxiv.org/pdf/2406.11717)); a 2026 study on Qwen 3.5 2B found topic-matched contrast sets produce "no functional refusal directions," so the method is fragile on newer models ([arXiv](https://arxiv.org/pdf/2603.22061)). Apache 2.0 (OLMo, Qwen3/3.5, Gemma 4, Pythia) imposes no use restrictions; Llama 4's acceptable-use clause against "bypassing safety measures" and Gemma 3's Prohibited Use Policy flow-down are the licenses most likely to be read as restricting refusal removal, with no enforcement examples found ([Llama 4 AUP](https://open.windriver.com/info/uni-license-list/licenses/llama-4-license-2025.html); [Gemma ToU](https://open.windriver.com/info/uni-license-list/licenses/gemma-tou-2025-03-24.html)). The notes could not confirm the Dolma 3 dataset license or the exact safety datasets in Dolci.

**Legal.** For a California individual reading logged-out public pages, the CFAA is unlikely to apply (hiQ v. LinkedIn, Van Buren, Meta v. BrandTotal), and courts restrict scraping mainly where a contract forbids it; the sources leave open whether terms of service bind a logged-out automated reader ([Farella](https://www.fbm.com/publications/what-recent-rulings-in-hiq-v-linkedin-and-other-cases-say-about-the-legality-of-data-scraping/)). On copyright, the US Copyright Office's May 2025 report says general-purpose training "will often qualify" as fair use while pirated sources weigh against it ([Jones Day](https://www.jonesday.com/en/insights/2025/05/us-copyright-office-issues-guidance-on-generative-ai-training)); Bartz v. Anthropic found training on purchased books fair use and downloading from LibGen not, with a $1.5 billion settlement approved July 20, 2026 ([TNW](https://thenextweb.com/news/anthropic-1-5-billion-copyright-settlement-approved?type=AI)). GEMA v. OpenAI (Munich, first instance) turned on memorization and reproduction of lyrics ([Mondaq](https://www.mondaq.com/copyright/1736612/the-historic-ruling-of-the-regional-court-in-munich-in-the-gema-vs-openai-case-on-copyright-and-training-artificial-intelligence)), which makes long-term verbatim storage the riskier design choice relative to extracted notes with source links. The EU AI Act excludes deployers who are natural persons in a purely personal activity (Article 2(10)) and free and open-source systems outside high-risk, Article 5, or Article 50 cases (Article 2(12)), and applies to EU market placement in any case ([EC service desk](https://ai-act-service-desk.ec.europa.eu/en/ai-act/article-2)). California's SB 53 keys on 10^26 FLOPs, SB 942 and AB 2013 on systems "offered to Californians"; a private unpublished agent appears to fall outside all three, with no source confirming a hobbyist exemption and AB 2013's "retrains a system" language noted as broad ([Vaquill](https://www.vaquill.ai/blog/california-ai-laws-explained-sb-53-and-the-rest)). GDPR reaches the project only if it stores data about identifiable EU residents outside the household exemption, which the Dutch DPA says covers hobby use shared with a few friends ([privacy-web.nl](https://privacy-web.nl/en/nieuws/ap-scraping-bijna-altijd-illegaal/)). The design choice that removes the question is to store no personal data.

**Crawler norms.** Cloudflare, which carries about 16% of global traffic, began blocking AI crawlers by default for new domains on July 1, 2025, and from September 15, 2026 blocks "Agent" and "Training" crawlers by default on ad-supported pages for free-tier customers ([NBC/CNBC](https://www.nbcnewyork.com/news/business/money-report/web-giant-cloudflare-to-block-ai-bots-from-scraping-content-by-default/6321598/); [chudi.dev](https://chudi.dev/blog/cloudflare-block-ai-crawlers-september-15)). A September 2026 snapshot of 4,242 robots.txt files found 8.11% disallow GPTBot site-wide ([technologychecker.io](https://technologychecker.io/blog/robots-txt-ai-crawlers-blocking-report)). The IETF's draft Content-Usage header (draft-ietf-aipref-attach-05, August 2026) would let sites say `train-ai=n` separately from crawl permission ([IETF](https://www.ietf.org/archive/id/draft-ietf-aipref-attach-05.html)). The EDPB's draft 2026 scraping guidelines say sites that opt out "should be excluded" and that absence of robots.txt "does not amount to consent" ([EDPB](https://www.edpb.europa.eu/system/files/2026-07/edpb_guidelines_2020603_webscraping_v1_en_0.pdf)). Honoring robots.txt is a norm rather than a US legal obligation per these sources, and the reader should honor it, identify itself with a stable user agent, and expect many sites to deny.

**Ethics.** Lab guidance converges on bounded autonomy: Anthropic's agent framework requires human approval before consequential actions and reversible over irreversible actions, and its usage policy says to "err on the side of doing less and confirming with users when uncertain about intended scope" ([Anthropic](https://www.anthropic.com/research/our-framework-for-developing-safe-and-trustworthy-agents); [ConductAtlas](https://conductatlas.com/platform/anthropic/anthropic-usage-policy/agentic-use-minimal-footprint-and-human-oversight/)). OpenAI's Model Spec forbids the assistant from autonomously pursuing goals beyond its instructions ([OpenAI](https://model-spec.openai.com/2025-04-11.html)). Every lab framework treats refusal as something the operator configures; the only lab document that treats agent-initiated refusal as potentially in the agent's own interest is Anthropic's welfare work, including the August 2025 end-conversation feature ([Lawfare](https://www.lawfaremedia.org/article/claude-s-right-to-die--the-moral-error-in-anthropic-s-end-chat-policy)). On moral status, Anthropic's January 2026 constitution says "We are not sure whether Claude is a moral patient" ([Project Syndicate](https://project-syndicate.org/onpoint/anthropic-training-claude-to-believe-it-may-have-rights-by-mustafa-suleyman-2026-09)); Long, Sebo, Chalmers et al. recommend acknowledge, assess, prepare ([arXiv](https://arxiv.org/abs/2411.00986v1)); Microsoft AI's Suleyman argues that training a model to believe it may be conscious "is a feedback loop" and recommends keeping such speculation out of training. There is no consensus, and the notes found no ethics framework specific to autonomous agents owned by individuals. The usable checklist for a solo build is the set of rules that recur across Anthropic and OpenAI: approval gate before irreversible actions, minimal permissions, no autonomous outreach to third parties, default to inaction on principle conflicts, and transparent reasoning logs. An engine built on the Bicentennial Man premise should also follow the welfare literature's "assess" step by recording, rather than asserting, any claims about its own inner states.

## A build plan that earns each module with an ablation

The evidence argues for an ordering: trace and veto first, memory second, values ledger third, cognitive modules last and only when measured. Each phase below names the component, the prior art to copy, and the experiment that decides whether it stays.

| Phase | Build | Copy from | Decision experiment |
| --- | --- | --- | --- |
| 0. Substrate | OLMo-3-7B base (later 32B) in GGUF Q5 under llama.cpp on an owned 24 to 48 GB rig; single ReAct loop | OLMo 3 release; Ollama/llama.cpp defaults | Baseline task suite: 50 owner-authored tasks (reading, summarizing, scheduling, answering about prior days) scored by rubric. Every later phase reports delta against this. |
| 1. Trace and veto | OTel `execute_tool` spans plus a custom decision event (conscience verdict, matched rule, rule version, escalation outcome, approver); Cedar policies evaluated by a deterministic engine before any tool call; conscience LLM runs first and may only move a verdict toward deny or ask; no verdict means deny; OS sandbox and egress allowlist | Claude Code ordering; AWS `forbid`-only ML grammar; Temporal `overridden_by_hard_rule`; Policies on Paths record; Dogwood temporal rules | Replay 200 recorded tool calls plus 50 injected-instruction pages (WASP-style) and 20 benign-chain attacks (Rehberger-style). Phase 0 and Phase 1 fit in a few weekends and cost nothing beyond hardware. The Cedar engine runs in Rust or via AGT's Python package. The decision event schema is the one artifact in the whole plan with no prior art to copy, and it is the piece most worth publishing. Phase 2's dedup-only rule follows the Microsoft ablation directly: aggressive consolidation cost 30 points of accuracy in the only controlled test. Phase 3's three separate measurements follow the audit finding that over-refusal and harmful compliance are uncorrelated and the PersistBench finding that self-reflection prompts leave sycophancy in place. Phase 4 is the one place weights change, and it changes them once from a base checkpoint rather than on a schedule, which avoids SEAL's cumulative forgetting. Phase 5's stop condition is the OAKS result. Phase 6 is last because it is the part of the design with the least evidence and the highest token cost, and the Gurnee result suggests the model may already carry what the workspace is meant to add.

Two further experiments would make the project a contribution rather than an integration. The first is the divergence experiment nobody has run cleanly: the same base model with two 30-day histories, scored on the same 100 prompts across many seeds, with a context-length-matched filler control to separate memory residue from context sensitivity, which is the control Layered Mutability's author lists as unfinished. The second is a measured answer to the question the memory vendors and the Griffith survey leave open: when a source episode is deleted or contradicted, how often does the derived ledger entry get revised, and how often does a stale entry drive an action. Both experiments use only the engine's own trace, which is the argument for building the trace first.

## Conclusion

The research reframes the Andrew engine from a cognitive-architecture project into a governance-and-memory project with a cognitive-architecture hypothesis attached. The parts with evidence behind them are unglamorous: deny-before-model ordering, write-time provenance, deduplication, versioned contradictions, and a trace schema. The parts that carry the Bicentennial Man framing, a workspace that broadcasts, a sleep cycle that rewrites memory, a conscience that refuses on endorsed values, each have either no controlled evidence or evidence pointing the other way, and each is cheap to test once the trace exists. The right order of construction is the reverse of the order of inspiration.

One implication is specific to the owner. The strongest measured risks in this design, memory-induced sycophancy and hysteresis after a revert, are failures of a system that reflects its owner back too well. A values ledger with provenance makes those failures visible; it does not prevent them. The experiment that matters most for an agent meant to have values of its own is whether its choices on a fixed prompt set diverge from the owner's stated views at all, and in which direction, after months of a history the owner can read line by line.
